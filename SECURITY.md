# Reporting a vulnerability
Please email the address in https://untrace.skysmindtech.com/.well-known/security.txt. Don't open a public issue for security problems.
Notes, drops and meetings are end-to-end encrypted and short-lived by design — if you find a way around that, we want to know.

## Sending something sensitive
Write your report as a `.txt`, lock it at https://untrace.skysmindtech.com/lockbox with a passphrase, and email the `.lockbox` file to sky@skysmindtech.com. Send the passphrase in a **separate** message (a Burn Note link works well: https://untrace.skysmindtech.com/note).
